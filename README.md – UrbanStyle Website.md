## 1. Project Overview

UrbanStyle is a modern fashion and lifestyle website created to showcase creative styling services, custom designs, and fashion ideas. The website was designed to provide visitors with an attractive and simple way of learning about the business, viewing its creative work, and contacting the organisation.

The website consists of five main pages: Home (`index.html`), About Us (`about.html`), Services (`services.html`), Gallery (`gallery.html`), and Contact (`contact.html`). Each page has been connected through a consistent navigation bar so that users can easily move between different sections of the website.

The website was developed using HTML5 for structure and CSS3 for presentation (MDN Web Docs, 2026a; MDN Web Docs, 2026b). Visual Studio Code was used as the primary development environment.

---

## 2. Purpose and Goals of the Website

The main purpose of the UrbanStyle website is to create a professional online presence for a modern fashion and lifestyle business, establishing brand identity and customer outreach.

**Website Objectives:**
1. Introduce visitors to UrbanStyle and its unique fashion identity.
2. Clearly outline the styling and design services offered.
3. Display creative work visually through a dedicated image gallery.
4. Provide accessible contact methods and an interactive front-end contact form.
5. Ensure seamless cross-page navigation and responsive mobile-friendly layouts.

---

## 3. Technologies Used

* **HTML5:** Used for semantic page structure, text formatting, form controls, and image embedding (MDN Web Docs, 2026a).
* **CSS3:** Used for visual styling, layout configuration, responsive media queries, and interactive pseudo-class states (MDN Web Docs, 2026b).
* **Visual Studio Code:** Used as the integrated development environment.
* **Live Server:** Used for local browser previewing during development.

6. Responsive Design & CSS Implementation
The website uses a centralized external stylesheet (style.css) to maintain visual consistency across all pages. Responsive design is handled through fluid width containers and media queries that adapt layouts for desktop screens, tablets, and mobile phones (W3C, 2026).

Interactive pseudo-classes (:hover, :focus, :active) are integrated into navigation links and buttons to ensure accessibility and feedback.
